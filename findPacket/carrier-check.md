# 物流查件入口核對

核對日期：2026-11-25。對應 findPacket 0.6 修正版，包含嘉里大榮、圓通 YTO 網址更新與 OK 超商「失聯中」標示；較早下載的 0.6 APK 需重新下載安裝修正版。

## 判定方式

- 檢查回應內容中的查件欄位、查件入口與官方網站連結，不能只憑 HTTP 200 判定可用。
- 舊入口無法使用時，先找官方新入口；沒有可用替代入口且目前持續連線失敗時，在選單標示「失聯中」。
- 搜尋索引只作為入口存在的佐證，不代表當下可連線。
- 防爬回應、動態頁面與網站逾時需個別判讀，不直接視為永久停用。
- 未輸入真實單號、未送出查件，也未完成 Android WebView 實機驗證。Windows 瀏覽器工具目前無法執行實際互動核對，因此動態載入與驗證碼流程仍有限制。
- 狀態是本次核對的固定資料，不是 app 執行時的即時偵測。

## 更新項目

- 嘉里大榮：舊 `https://www.express.com.tw/tools/positchecking.aspx` 發生 TLS 主機名稱不符；官方 `https://www.kerrytj.com/` 導向 `/zh/`，並直接連至 `/zh/checking`。新頁回應正常且包含貨物追蹤表單，改用 `https://www.kerrytj.com/zh/checking`。
- 圓通 YTO：從舊英文首頁改用官方「我要查件」專頁 `https://www.yto.net.cn/ytoExpress/waybill/search/`，可讀到運單號輸入與查詢按鈕。
- OK 超商：原查件網址與查件站根目錄多次回應 HTTP 504，搜尋仍指向原址，未找到官方替代入口。本次選單標示「OK 超商（失聯中）」，保留原址供重試。這不代表永久停用。
